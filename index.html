02 · Reveal

基于 IntersectionObserver，声明式 data 属性，支持分组错峰与九种动画。

03 · Transition

路由切换过渡

与路由库解耦，优先使用 View Transitions API，不支持时回退为全屏遮罩。

Home

把每一次跳转做成一次开场

切换标签会执行 transition.run(() => 更新页面)，离场、更新、入场自动串起来。

想用自己的 GIF？

把文件放到 demo/assets/loading.gif，然后： 

createIntro({
  variant: 'curtain',
  media: { src: '/demo/assets/loading.gif', width: 160 },
  loader: 'none',
  minDuration: 900,
  preload: ['/demo/assets/loading.gif'],
})

也支持 WebP / APNG / SVG / PNG / JPG 与 mp4 / webm 视频，或直接传入一个 HTMLElement 完全自定义开场内容。
